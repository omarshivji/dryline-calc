
# Dryline® Material Calculator User Guide

> **Version:** Qantra Digital Consultancy v1.0

## Introduction

A step-by-step guide to quoting drylining jobs faster—from room dimensions to a full materials takeoff, on site or in the office.

---

# 1. Getting Started

## 1.1 Installing the App

The calculator installs to your home screen (no App Store required) and works offline once installed.

### Steps

1. Open the link in **Safari** (iPhone only).
2. Tap the **Share** icon.
3. Select **Add to Home Screen**.
4. Launch the app from your home screen.

> **Tip:** Core features work offline. Floor plan PDF upload requires an internet connection the first time it is used each session.

## 1.2 Light & Dark Mode

Use the toggle in the top-right corner.

| Mode | Best For |
|------|----------|
| 🌙 Dark | Low-light conditions, OLED battery saving |
| ☀ Light | Bright daylight and outdoor use |

---

# 2. Room Setup

## 2.1 Entering Room Dimensions

| Field | Description |
|------|-------------|
| Length & Width | Internal room dimensions (m) |
| Ceiling Height | Floor-to-ceiling height (m) |
| Doors / Windows | Quantity and average area |
| Wastage | Percentage allowance (10% recommended) |

> **Note:** Door and window areas are deducted automatically.

## 2.2 Camera Scan Measuring

1. Tap **Scan Length**, **Scan Width**, or **Scan Height**.
2. Take a straight-on photo.
3. Mark a known reference length.
4. Mark the required measurement.

### Accuracy

This is intended as a fast on-site estimate. Use a tape measure where precision is required.

---

# 3. Floor Plans

## 3.1 Measuring from a Floor Plan

1. Tap **Upload Floor Plan**.
2. Select a PDF, JPG, or PNG.
3. Calibrate using a known dimension or scale.
4. Mark the two room walls.
5. Confirm and apply the measurements.

> **Note:** Only the first page of multi-page PDFs is used.

---

# 4. Materials Output

## 4.1 Board & Layer Settings

| Setting | Options |
|---------|---------|
| Board Size | 2400×1200mm, 2700×1200mm, 3000×1200mm |
| Layers | Single or Double |
| Insulation | On / Off |

## 4.2 Materials List

After entering dimensions the calculator automatically estimates:

- Plasterboard
- Drywall screws
- Jointing tape
- Joint compound
- Insulation (if enabled)

### Advanced Coverage Rates

Adjust:

- Screws per m²
- Tape coverage
- Compound coverage
- Insulation wastage

## 4.3 Copying a Quote

Select **Copy Quote** to copy a formatted materials list for use in WhatsApp, SMS, or written quotations.
